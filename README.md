# ⭐ Projetos em destaque

## 🔐 Sanitizador LGPD

Ferramenta desenvolvida em **Python** para identificar e sanitizar dados pessoais e sensíveis antes que sejam enviados para APIs de Inteligência Artificial.

O projeto possui foco em **privacidade, segurança, testes automatizados e prevenção de vazamento de dados**.

### Principais recursos

- Identificação de dados pessoais (CPF, CNPJ, cartões, e-mails, telefones e outros)
- Validação de CPF/CNPJ e de cartões (algoritmo de Luhn)
- Tratamento de formatos variados (pontos, traços e barras)
- Detecção de dados sensíveis
- Sanitização e pseudonimização
- Auditoria das operações
- Fluxo de aprovação humana
- Testes automatizados
- Integração com LLM
- Teste garantindo que dados reais não sejam enviados ao modelo

### Tecnologias

`Python` `unittest` `LLM` `LGPD` `Security` `GitHub Actions`

🔗 **[Ver projeto no GitHub](https://github.com/JVCO30/Sanitizador-LGPD)**
